## 🔄 데이터 흐름

### 1️⃣ 문서 업로드 과정
```
사용자 PDF/텍스트 파일 → FastAPI 서버 → 문서 처리 서비스 → 텍스트 추출 → 청킹 → 벡터화 → FAISS 저장
```

### 2️⃣ 질의응답 과정
```
사용자 질문 → 챗봇 모델 → 벡터 검색 → 관련 문서 찾기 → 컨텍스트 생성 → AI 응답 생성 → 사용자에게 전송
```

## 🧠 핵심 컴포넌트 설명

### 1. **FastAPI 서버** (`app/main.py`)
- **역할**: 웹 API 엔드포인트 제공
- **주요 기능**:
  - LINE 웹훅 수신
  - 문서 업로드 처리
  - 챗봇 응답 생성
  - API 라우팅

### 2. **향상된 챗봇 모델** (`app/models/enhanced_chat_models.py`)
- **역할**: RAG 기반 응답 생성
- **주요 기능**:
  - 사용자 질문 분석
  - 관련 문서 검색
  - 컨텍스트 생성
  - AI 모델 호출

### 3. **문서 처리 서비스** (`app/services/pdf_service.py`)
- **역할**: 문서 로드 및 벡터화
- **주요 기능**:
  - PDF/텍스트 파일 로드
  - 텍스트 청킹
  - 벡터 임베딩 생성
  - FAISS 벡터 스토어 관리

### 4. **스포츠 서비스** (`app/services/sports_service.py`)
- **역할**: 스포츠 데이터 제공
- **주요 기능**:
  - 경기 일정 정보
  - 팀 순위 정보
  - 뉴스 데이터

## 🔧 기술 스택

### 백엔드
- **FastAPI**: 웹 프레임워크
- **Uvicorn**: ASGI 서버
- **Python**: 프로그래밍 언어

### AI/ML
- **LangChain**: LLM 애플리케이션 프레임워크
- **Google Gemini**: 대화형 AI 모델
- **FAISS**: 벡터 데이터베이스
- **Sentence Transformers**: 텍스트 임베딩

### 데이터 처리
- **PyPDF**: PDF 파일 처리
- **LangChain Text Splitters**: 텍스트 청킹
- **Google Generative AI**: 임베딩 생성

## 🎯 주요 API 엔드포인트

### 1. **웹훅 처리**
```
POST /webhook/{sport_type}
```
- LINE 채널에서 메시지 수신
- 사용자 질문 처리
- 응답 전송

### 2. **문서 업로드**
```
POST /upload-document/{sport_type}
```
- PDF/텍스트 파일 업로드
- 문서 처리 및 벡터화
- FAISS 저장

### 3. **향상된 채팅**
```
POST /enhanced-chat/{sport_type}
```
- RAG 기반 응답 생성
- 문서 참조 포함

### 4. **문서 정보 조회**
```
GET /documents/{sport_type}
```
- 저장된 문서 목록 조회
- 문서 수량 확인
