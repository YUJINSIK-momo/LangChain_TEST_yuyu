## 💡 핵심 개념 요약

### 🔄 RAG (Retrieval Augmented Generation)
- **검색**: 관련 문서 찾기
- **생성**: AI가 답변 생성
- **결합**: 검색 + 생성 = 정확한 답변

### 🏗️ LangChain
- **프레임워크**: LLM 애플리케이션 개발
- **모듈화**: 재사용 가능한 컴포넌트
- **확장성**: 다양한 도구 통합

### 🎨 프롬프트 엔지니어링
- **최적화**: AI 응답 품질 향상
- **구조화**: 명확한 지시사항
- **일관성**: 일관된 톤앤매너

### 🚀 LangGraph (향후)
- **복잡성**: 고급 워크플로우 관리
- **조건부**: 상황별 분기 처리
- **상태**: 대화 맥락 유지
